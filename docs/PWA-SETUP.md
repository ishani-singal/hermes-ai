# PWA Setup Guide

## ✅ What's Been Implemented

Your Hermes AI Technician Assistant is now a **Progressive Web App (PWA)** ready for iOS!

### Features Added:
1. **Web App Manifest** (`/public/manifest.json`)
   - App name: "Hermes AI"
   - Full name: "Hermes AI Technician Assistant"
   - Standalone display mode for app-like experience
   - Splash screen configuration

2. **Service Worker** (auto-generated by next-pwa)
   - Offline caching for static assets
   - API response caching (24hr TTL)
   - Smart cache strategies for different resource types

3. **iOS-Specific Metadata**
   - Apple touch icon (180x180)
   - Status bar styling
   - Viewport optimization for mobile
   - Theme color configuration

4. **Icons**
   - 192x192 icon for Android/PWA
   - 512x512 icon for high-res displays
   - Apple touch icon for iOS home screen

## 📱 Testing on iPhone

### Method 1: Using Safari (Recommended)
1. Deploy your app to a public URL (Vercel, Netlify, etc.)
2. Open the URL in **Safari on iPhone** (must be Safari, not Chrome)
3. Tap the **Share button** (square with arrow)
4. Scroll down and tap **"Add to Home Screen"**
5. Confirm the name "Hermes AI" and tap **Add**
6. The app icon appears on your home screen!

### Method 2: Local Testing (Advanced)
1. Get your local machine's IP: `ipconfig` (look for IPv4 address)
2. Update your `.env.local` to allow that IP
3. Start dev server: `npm run dev`
4. On iPhone, connect to same WiFi
5. Open Safari and go to `http://YOUR_IP:3000`
6. Follow "Add to Home Screen" steps above

**Note:** PWA is disabled in development mode. Use production build:
```bash
npm run build
npm start
```

## 🚀 Production Deployment

### Vercel (Recommended)
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

### Manual Deployment
1. Build the app: `npm run build`
2. The service worker files will be generated in `/public/`:
   - `sw.js` (service worker)
   - `workbox-*.js` (workbox runtime)
3. Deploy the entire `.next` and `public` folders to your hosting

## 🔧 Configuration

### PWA Settings (`next.config.ts`)
- **Offline Mode**: Enabled with smart caching
- **Cache Duration**: 24 hours for most assets
- **API Caching**: Network-first with 10s timeout fallback
- **Dev Mode**: PWA disabled (for faster development)

### Manifest Settings (`public/manifest.json`)
- **Display**: Standalone (full-screen app)
- **Orientation**: Portrait (primary)
- **Theme**: Black (#000000)

## 📊 Cache Strategies

| Resource Type | Strategy | TTL | Notes |
|--------------|----------|-----|-------|
| Google Fonts | CacheFirst | 365 days | Long-term cache |
| Static Assets | StaleWhileRevalidate | 24 hours | Images, CSS, JS |
| Next.js Data | StaleWhileRevalidate | 24 hours | Page data |
| API Routes | NetworkFirst | 24 hours | 10s timeout → cache |

## 🐛 Troubleshooting

### "Add to Home Screen" doesn't appear
- ✅ Must use **Safari** (not Chrome/Firefox)
- ✅ Must be on **HTTPS** (or localhost)
- ✅ Service worker must be registered (check Console)

### App doesn't work offline
- Service worker only active in **production** (`npm run build && npm start`)
- Check Network tab → Service Worker status
- Clear cache and reload

### Icons don't show up
- Verify files exist: `/public/icon-192.png`, `/public/icon-512.png`
- Check manifest.json paths are correct
- Hard refresh browser (Cmd+Shift+R)

### Service worker not updating
```bash
# Clear Next.js cache
rm -rf .next

# Rebuild
npm run build
```
